= OnCloud — CDP Public Cloud HoL Automation
:toc: preamble
:icons: font

**AutoClouderaDeploy** provisions disposable Cloudera Data Platform Public Cloud Hands-on Lab environments from a single Docker container — CDP environment, datalake, optional data services (CAI, CDW, CDE, CDF), Keycloak SSO, and workshop users.

|===
| Cloud | Directory | Published image

| AWS
| link:AWS/build/README.adoc[`AWS/build/`]
| `clouderapartners/cdp-public-cloud-hol-provisioner:latest`

| Azure
| link:Azure/build/README.adoc[`Azure/build/`]
| `clouderapartners/cdp-public-cloud-hol-provisioner-azure:latest`
|===

== Choose your cloud

Both provisioners share the same workflow: mount a `userconfig` directory with a `configfile`, run `provision` or `destroy`, and collect workshop access details from `{WORKSHOP_NAME}.txt`.

Long runs (1–3+ hours): use foreground `docker run --rm` (default), or optional detach mode (`-d` + `docker logs -f`) and per-service logs under `~/hol-userconfig/.{WORKSHOP_NAME}/logs/` — see link:AWS/build/README.adoc#_optional_run_in_background_d[AWS] or link:Azure/build/README.adoc#_optional_run_in_background_d[Azure] runbooks.

* link:AWS/build/README.adoc[AWS runbook] — quick start, developer build/tag/push, Jenkins jobs
* link:Azure/build/README.adoc[Azure runbook] — quick start, developer build/tag/push, Azure enhancements (CDW/CDE identities, CAI NFS)
